ACID

When people say a database is trustworthy, they usually mean it holds these four properties. Here is what each one actually guarantees, without the textbook hedging.

Atomicity means the transaction either happens or it does not. There is no third state, no half-written row that a crash leaves behind.

Consistency is a property of your rules, not of the engine that enforces them.

Isolation is about concurrent transactions. Durability is about power. A commit that returns OK survives a crash the moment after.

BEGIN;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;
COMMIT;
